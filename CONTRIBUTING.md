# Участие в разработке

**Русский** | [English](CONTRIBUTING.en.md)

Предложения и ошибки принимаются через Issues. Для изменения кода создайте ветку
и Pull Request с описанием результата и проверки.

```powershell
npm ci --omit=optional
npm test
npm run desktop
```

Нужен Node.js 24+. Автотесты поднимают локальные серверы на свободных портах.
Для проверки настоящего Web Browser Input требуется Windows с vMix.

Новые команды меняйте одновременно в генераторе `src/server/vmix-commands.js`,
готовых файлах `integrations/vmix` и руководстве. Сохраняйте совместимость имён
старых источников и путь существующей библиотеки. Чтение ответов фоновых запросов
обязательно; исправление 0.9.6 предотвращает удержание ресурсов браузера.

Перед отправкой выполните `npm test`. Для интерфейса проверьте обе темы,
клавиатуру, диалоги, ширину 375/760 px и сохранение текущего показа.
Пользовательские PDF, профили, резервные копии и локальная диагностика в Git не включаются.

Изменения принимаются под лицензией MIT проекта.

Поддерживайте русскую и английскую документацию в актуальном состоянии.
