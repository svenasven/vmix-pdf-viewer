      Удалить PDF?

      Подключение к vMix

      На этом компьютере · vMix 4K / Pro / Trial

      1

      Подключите источник PDF

      Запустите vMix. Мы добавим источник и будем обновлять его адрес при смене порта.

      Порт подключения

      Проверяем подключение…

      Для существующего источника будет изменён адрес страницы. Сохраните пресет vMix после подключения.

      2

      Установите готовые команды

      Сохраните нужные файлы ниже. Для каждого файла в vMix: Settings → Scripting → Add. Вставьте имя кнопкой «Копировать имя», нажмите Import, выберите файл, затем Save → Close. Код редактировать не нужно.

      Если команда уже есть: Edit → Import → Save → Close. Имена должны совпадать точно.

      3

      Добавьте клавиши управления

      Готовый набор: Page Down — вперёд, Page Up — назад. Сначала установите команды из шага 2.

      Сохранить набор для vMix
      1. В vMix откройте Settings → Shortcuts → Templates.
      2. Нажмите Import и выберите сохранённый файл.
      3. Выберите vMix PDF Viewer — страницы, нажмите Apply, затем Close → OK.

      Импорт может заменить существующие сочетания. Сначала сохраните их через Export. Для добавления отдельных кнопок используйте способ ниже.

      MIDI, свои клавиши и смена PDF

      В vMix: Settings → Shortcuts → Add → Find. Нажмите нужную клавишу или MIDI-кнопку. Выберите Function: ScriptStart, в поле Script Name вставьте имя нужной команды из шага 2. Следующий PDF — PDF_NextDocument, предыдущий — PDF_PreviousDocument.

      Для MIDI используйте срабатывание на нажатие без повторной команды при отпускании.

      4

      Проверьте показ

      Эти кнопки отправят команду через vMix и изменят страницу текущего PDF.

      Затем переключитесь в vMix и проверьте назначенные клавиши или MIDI-кнопки. Проверка здесь не проверяет их назначение.

      Резервная копия

      Сохранить библиотеку

      Все PDF, их порядок, последняя страница и порт подключения к vMix — в одном файле.

      Сохранить копию

      Восстановить из файла

      В заполненную библиотеку документы добавятся в конце списка. Текущий показ не изменится. На пустой библиотеке восстановятся порядок и последняя страница.

      На другом компьютере подключите источник vMix через мастер настройки. Существующая привязка к vMix при добавлении документов сохраняется.
