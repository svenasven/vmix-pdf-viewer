# Руководство оператора

**Русский** | [English](en/user-guide.md)

## Документы и показ

Нажмите «Добавить PDF», выберите один или несколько файлов. Первый PDF откроется
автоматически. «Показать» открывает документ с начала. Миниатюра выбирает страницу;
стрелки, первая/последняя и поле номера управляют текущим документом.

Перетащите документ в очереди или используйте стрелки рядом с ним. Для удаления
неактивного PDF нажмите корзину и подтвердите. Активный PDF удалить нельзя:
сначала выберите другой. Перестановка и удаление остальных сохраняют текущий показ.
Ограничение одного PDF — 50 мегабайт. Защищённые и повреждённые файлы отклоняются.

## vMix

В vMix включите Web Controller/API. В приложении откройте «Настройки → Настроить vMix».
Нажмите «Найти vMix», выберите источник или добавьте новый. Приложение обновляет
адрес при смене порта автоматически. Рекомендуемый размер Browser Input — 1920 × 1080.
После настройки сохраните пресет vMix.

После перезапуска vMix приложение автоматически восстанавливает подключение
к сохранённому источнику и продолжает показ текущего документа.

«Проверить подключение» показывает связь с API, наличие выбранного источника
и подтверждение нужной страницы. Восстановление переподключает тот же источник.
Готовность страницы не означает, что источник в эфире: Program контролируется в vMix.

## Клавиши, кликер и MIDI

В мастере сохраните готовые файлы команд. Для каждого в vMix:
**Settings → Scripting → Add → Import → Save → Close**. Имя скопируйте из мастера.
Для Page Down / Page Up импортируйте шаблон Shortcuts из мастера.
Перед Apply сохраните текущие сочетания через Export: импорт может их заменить.

Для отдельной клавиши или MIDI: **Settings → Shortcuts → Add → Find**, нажмите кнопку,
выберите **Function: ScriptStart**, укажите имя команды:

| Имя | Действие |
|---|---|
| PDF_Next / PDF_Previous | Следующая / предыдущая страница |
| PDF_NextDocument / PDF_PreviousDocument | Следующий / предыдущий документ |
| PDF_First / PDF_Last | Первая / последняя страница |

Для MIDI настройте одно срабатывание на нажатие. Управление MIDI работает
через vMix Shortcuts.

Команды до 0.10 работают со старыми источниками. Новые файлы понимают оба имени.
Для нового источника `vMix PDF Viewer @порт` обновите старые команды через
Edit → Import. Имена команд и Shortcuts сохраняются.

## Тема, сеть и резервные копии

Логотип слева — переключатель темы. Работают нажатие, Enter и Space;
подсказка сообщает, какая тема включится. Выбор сохраняется после смены порта.
Первый запуск учитывает системную тему. Цвета PDF не изменяются.

Адреса локальной сети доступны в настройках. Откройте адрес на устройстве той же
подсети. Все подключённые устройства доверенной сети получают управление библиотекой.

«Настройки → Резервная копия» сохраняет библиотеку, порядок, страницу и порт API vMix.
В заполненную библиотеку восстановление добавляет PDF без смены текущего показа.
На новом компьютере вновь подключите источник через мастер.

Крестик скрывает окно в область уведомлений. Показ и команды продолжают работать.
Нажатие на значок открывает окно. Для выхода: меню значка → «Выйти».
