# Архитектура

**Русский** | [English](en/architecture.md)

Приложение запускает локальный HTTP-сервер и открывает панель в окне Electron.
vMix загружает `/output` через Web Browser Input. PDF.js, шрифты, CMaps и WASM
обслуживаются локально. Интернет при показе не требуется.

```text
src/main/    Окно, значок, preload, запуск Node-only сервера
src/server/  HTTP API, библиотека, копии, vMix Bridge, диагностика
src/web/     Панель, темы, PDF.js session, миниатюры, вывод
integrations/vmix/  Команды VB и шаблон Shortcuts
tests/       Проверки API, данных, совместимости, темы и окна
assets/      Иконки приложения
LICENSES/    Лицензии сторонних ресурсов
.github/     Проверки и сборка Windows
```

Состояние содержит sessionId, documentId, revision и страницу. Вывод опрашивает его
последовательно. Рендер идёт во вспомогательный canvas; перед заменой кадра
проверяются ревизия и размер. Устаревшая отрисовка не заменяет новый кадр.
При смене PDF освобождается прежняя PDFDocumentLoadingTask.

Выход отправляет heartbeat с идентификатором источника и состоянием рендера.
Предпросмотр отмечен отдельно и не подтверждает готовность vMix. Ответы
фонового heartbeat полностью считываются до следующего запроса.

Electron запускает сервер в Node-only процессе того же EXE. При выходе или
потере родителя сервер завершается. Профиль остаётся `%APPDATA%/PDF Viewer`,
чтобы новое имя не создало пустую библиотеку. Очередь проверяет revision;
активный PDF защищён от удаления на сервере.

Сервер слушает локальные интерфейсы, проверяет Host, Origin и подсеть клиента.
Свободный порт подтверждается loopback-запросом с учётом wildcard bind Windows.
vMix Bridge обновляет адрес выбранного источника.

Старые входы `PDF Viewer @порт` сохраняют префикс для установленных VB-команд.
Новые получают `vMix PDF Viewer @порт`. Новые команды понимают оба формата;
при нескольких подходящих входах отказываются выбирать наугад.

`theme.js` выполняется до CSS. Сохранённая тема приоритетнее системной. Cookie
сохраняет выбор для хоста независимо от порта, localStorage — запасной вариант.
При блокировке хранения переключатель остаётся рабочим. `theme.css` влияет
только на панель: вывод PDF имеет собственные страницу и стили.
