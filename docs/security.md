# Сеть и данные

Приложение предназначено для доверенной локальной сети. Устройства той же
подсети могут менять документы и управлять показом. Встроенных учётных записей,
паролей и разграничения прав нет. Не публикуйте порт приложения в интернете.

Сервер проверяет Host, Origin и подсеть: это ограничивает посторонние веб-страницы,
но не заменяет авторизацию устройств вашей сети. API vMix вызывается на loopback.

PDF и профиль хранятся локально. Резервный файл `.pdfviewer-backup` содержит сами
документы. Тема в cookie/localStorage не содержит данных библиотеки.

В Git входят исходники, документация и созданные для примера скриншоты.
Рабочая библиотека, профили, дампы и копии не входят в исходную поставку.
Для сообщения об уязвимости сначала согласуйте с владельцем приватный способ
передачи деталей. Не прикладывайте конфиденциальные PDF или секреты.
